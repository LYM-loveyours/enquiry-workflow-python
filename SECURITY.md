# Security and scope
This is a demonstration repository, not an operated production service. Use synthetic data only. Do not submit credentials, personal data or security reports through public issues.

Report suspected vulnerabilities privately to hq@loveyoursmedia.com with the repository name, affected version and safe reproduction steps. Do not include a live credential. The maintainer will assess the report; no response-time SLA is promised.

The first public release supports only the dependency versions in its lockfiles. No production integrations, live messages or payment processing are included. Updates require review and repeat testing.
